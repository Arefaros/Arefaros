## Flagship Project: BloomEval

<p align="center">
  <a href="https://bloomeval-playground.pages.dev">
    <img src="https://img.shields.io/badge/Status-Production_Live-10b981?style=flat-square" alt="Status: Production Live" />
  </a>
  <img src="https://img.shields.io/badge/Infra_Cost-RM0.00%2Fmo-00f0ff?style=flat-square" alt="Infra Cost: RM0.00/mo" />
  <img src="https://img.shields.io/badge/Scoring_Parity-Pearson_r_%3D_0.942-6366f1?style=flat-square" alt="Scoring Parity: Pearson r = 0.942" />
  <img src="https://img.shields.io/badge/Architecture-Cloudflare_Edge_%2B_Gemini-f38020?style=flat-square" alt="Architecture: Cloudflare Edge + Gemini" />
</p>

> **Live Platform:** [bloomeval-playground.pages.dev](https://bloomeval-playground.pages.dev)  
> **Source Repository:** [github.com/Aliffros/bloomeval](https://github.com/Aliffros/bloomeval)

BloomEval is an automated pedagogical evaluation and cognitive depth framework tailored to Malaysian secondary school ESL writing (SPM 1119 Paper 2 / CEFR format):

- Client-side canvas downscaling processes physical handwritten foolscap scripts under 400 KB and extracts paragraphs via multimodal vision in under two seconds with zero server file persistence.
- Dual-pathway engine enforces official Lembaga Peperiksaan Malaysia band descriptors across Content, Communicative Achievement, Organisation, and Language alongside Bloom's Revised Taxonomy cognitive mapping.
- Boundary guardrails catch word-count violations, prompt topic divergence, and adversarial submissions before LLM evaluation.
- Edge deployment on Cloudflare Pages and Cloudflare D1 operates continuously at RM0.00 monthly infrastructure cost.
- Empirical benchmark across 120 student essays demonstrated Pearson r = 0.942 scoring parity against certified examiners and an 88.50 System Usability Scale rating.
